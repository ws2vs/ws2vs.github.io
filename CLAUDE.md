## Project Overview

This is a Docusaurus 2 static documentation and blog site hosted on GitHub Pages at https://ws2vs.github.io/.

## Commands

```bash
yarn start        # Start local development server with hot reload
yarn build        # Build static site for production
yarn deploy       # Deploy to GitHub Pages (gh-pages branch)
yarn serve        # Serve the built production site locally
```

## Content Structure

- `docs/` - Documentation pages (with categories: FE, JS, common-commands, misc)
- `blog/` - Blog posts (Markdown files with date prefix)
- `docusaurus.config.js` - Site configuration
- `sidebars.js` - Documentation sidebar structure (autogenerated from filesystem)

## Adding Content

- Docs: Create Markdown files in `docs/` with optional `_category_.json` for sidebar grouping
- Blog: Create Markdown files in `blog/` with format `YYYY-MM-DD-title/index.md`

## Dependencies

Node.js >= 16.14 required. Install with `yarn`.
